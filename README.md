## 📌 Visão Geral

Aplicação full stack distribuída para coleta, processamento e visualização de dados climáticos, com geração de insights automatizados.

Desenvolvida com foco em arquitetura de sistemas, integração entre serviços, mensageria (RabbitMQ) e processamento assíncrono.

---

## 🎯 Destaques Técnicos

* Arquitetura distribuída
* Comunicação assíncrona
* Integração entre múltiplos serviços
* Processamento de dados com workers
